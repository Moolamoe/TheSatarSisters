# Satar Sisters on GitHub Pages

The website is contained in index.html, including all four views, styling, booking links and Instagram embeds. README.md is this guide. No installation or build command is required.

## Publish from your browser

1. Extract this ZIP. On Windows, right-click it and choose Extract All.
2. Sign in to GitHub and visit https://github.com/new. Name the repository satar-sisters. For GitHub Free, select Public. Turn on Add a README file and click Create repository. If you already created the website repository, open it instead.
3. On the Code tab, select Add file, then Upload files. Drag index.html into the upload area. If the repository is empty, use the uploading an existing file link instead. Commit the file to your main branch. Confirm that index.html appears at the top level of the repository. You can keep this guide on your computer.
4. In the repository, open Settings, then Pages. Under Build and deployment, choose Deploy from a branch. Select main and / (root), then Save. If you use another default branch, select the branch containing index.html.
5. Allow up to 10 minutes for the first publication. Return to Settings, then Pages, and click Visit site. For a repository named satar-sisters the address is normally https://YOUR-USERNAME.github.io/satar-sisters/.
6. Open each practice, the catalogue and the booking links. Instagram supplies the images over the internet. If a feed is blocked, its View profile link opens the corresponding Instagram account.

## Update later

Upload your revised index.html to the same branch and commit it. GitHub Pages republishes from that branch. A 404 after the initial deployment usually means the Pages source or the location and spelling of index.html needs checking. The Actions tab shows the deployment status.
